# Bisit Bar React Web App

Premium React + Vite version of the Bisit Bar Bench Cultural Celebration website.

## Components
- Navbar.jsx
- Hero.jsx
- About.jsx
- Culture.jsx
- Testimonials.jsx
- Program.jsx
- Gallery.jsx
- Location.jsx
- RSVP.jsx
- Footer.jsx

## Run
```bash
npm install
npm run dev
```

Put your media in `public/assets/`:
`hero-1.jpg`, `hero-2.jpg`, `bisit-bar-hero.mp4`, `testimony-1.mp4`, `person-1.jpg`, `person-2.jpg`, `person-3.jpg`, and `culture-1.jpg` through `culture-6.jpg`.
